# Modelo de tela de cadastro

Este repositório constitui um exemplo simples de 
tela de cadastro de produtos em firefired 3 que pode ser ampliado
para dar mais funcionalidades.

## Possibilidades de extensão das funcionalidades 


Um exemplo para um próximo passo é implementar
uma interface para disacoplar mais o singleton
de conexão do banco de dados (visando flexibilidade
maior de uso de outros bancos de dados)

Uso de frames para flexibilidade de uso em
manutenção de outros cadastros, entre outras
expansões possíveis com algumas extensões.
